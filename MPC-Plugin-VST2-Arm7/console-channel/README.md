# Console Channel

Four-page original channel strip. DSP currently includes input gain/polarity, first-order HPF/LPF, four-band tone shaping, compressor envelope/ratio, gate, peak limiter, wet/dry and output trim. Stereo processing uses per-instance state.

The current filter/EQ and dynamics implementation is a lightweight first-pass DSP, not a claim of exact analogue circuit modelling. Listen-test and tune thresholds/timing on the target hardware before release.
